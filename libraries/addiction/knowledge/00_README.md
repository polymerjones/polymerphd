# 00 — README

This package synthesizes {videos} sources on addiction, compulsion, and behavior change — drawn
from creators across psychology, journalism, and self-improvement writing, not a single channel or
clinical corpus. It covers phone/tech addiction, habit mechanics, goal and values psychology, and
nervous-system-based behavior change.

## What this collection is, and isn't

Every video here approaches "why do we keep doing the thing we don't want to do, and what actually
breaks the pattern" from a different discipline — a habit-science journalist, two sports-and-
performance writers working from one book, a clinical psychologist, a productivity author, and a
philosophy-and-social-psychology writer. None of them are addiction-medicine clinicians treating
substance-use disorder directly; several explicitly reach for addiction and substance-dependence
comparisons (heroin, "the same neurochemistry") as a rhetorical anchor for describing modern
behavioral traps like phone use and status-chasing, not as clinical claims about diagnosable
addiction. That distinction is worth keeping in mind throughout this package.

## How this package is organized

- **01_CORE_PRINCIPLES.md** — the patterns that recur across separately-produced videos from
  different creators, treated as this collection's load-bearing ideas.
- **02_MECHANISMS_OF_COMPULSION.md** — the "why": the specific mechanisms each source names for why
  a pattern persists (dopamine, the habit loop, nervous-system familiarity, disevolution).
- **03_BREAKING_THE_LOOP.md** — the "what to do": practices and techniques collected across sources
  for interrupting or replacing a compulsive pattern.
- **04_SIGNALS_AND_SELF_ASSESSMENT.md** — the internal states and signals sources say to watch for,
  gathered across all eleven notes.
- **05_CROSS_SOURCE_COMPARISON.md** — where different creators' frameworks converge, extend each
  other, or use different vocabulary for what looks like the same underlying claim.
- **06_OPEN_QUESTIONS.md** — claims stated without a named source, internally hedged, or otherwise
  worth treating with more caution than the collection's more directly cited material.
- **07_PLAIN_ENGLISH_GLOSSARY.md** — every named term, alphabetically, no citations.
- **08_QUESTIONS_AND_ANSWERS.md** — worked example answers in this package's own voice.
- **09_SOURCE_CATALOG.md** — every source, auto-generated, regenerates itself after each new note.

Per this project's provenance rule, files 01–08 carry no video-ID citations — only the individual
notes in this library's `notes/` folder do that.
