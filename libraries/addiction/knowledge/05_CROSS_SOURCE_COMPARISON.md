# 05 — Cross-Source Comparison

Where this collection's creators converge, extend each other, or use different vocabulary for what
looks like the same underlying claim. Individual notes carry the specific, timestamped version of
each comparison below — this file gathers the pattern across all of them.

---

## Convergence: willpower is not the mechanism, and shouldn't be the strategy

Every source that addresses behavior change directly arrives at some version of the same claim —
that the target behavior runs on a mechanism other than conscious willpower, using different
vocabulary: a dopamine anticipation-of-reward signal; an automated cue-routine-reward loop; an
emotionally-driven "feeling brain" that a rational "thinking brain" can only steer, not override; a
nervous system defending a familiar pattern. None of these sources appear to be responding to each
other directly — the convergence looks like independent arrival at a similar conclusion from
different disciplinary starting points (habit science, neuroscience communication, philosophy,
clinical psychology).

## Convergence: small steps beat large ones, across every framework

The "small, sustained increment" principle (see `01_CORE_PRINCIPLES.md`) shows up in essentially
every source that offers a change technique, using different names: an "implementation intention"
(habit science), keeping most effort at 5-7 out of 10 intensity and stopping "one rep short"
(sports performance), a "small daily promise" (clinical psychology), and shrinking a resisted task
down until it's small enough to start (productivity writing). These are not the same technique, but
they share a common shape and appear to be independently-derived versions of one underlying idea.

## Convergence: two independent value-alignment frameworks

Two sources independently converge on the claim that a goal or behavior's durability depends on
alignment with a person's genuine values, using incompatible but complementary specific frameworks:
one names three abstract tests for a good value (immediate/controllable, reality-based, socially
constructive) plus practical exercises (a time audit, a deathbed exercise) for surfacing actual
values; the other cites a named academic taxonomy of twelve specific values and a five-layer
"intention stack" connecting values down to moment-to-moment action. Despite different structures,
both treat a values conflict as the explanation for otherwise-unexplained resistance to a
reasonable-looking goal.

## Notable coincidence: identical phrasing, different targets

Two different creators in this collection each use the phrase "sepia-toned" to describe something
that looks appealing as an idea but is disliked in lived reality — one applies it to *goals*
specifically (a goal that sounds good in the abstract but is resented once actually lived day to
day), the other to *values or identity aspirations* more broadly. Both are Big Think Clips uploads,
which makes a shared editorial or cultural source for the phrase plausible, but nothing in either
transcript indicates the two speakers are quoting or referencing each other — treated here as an
interesting convergence in language rather than a documented influence.

## Extension: the same reframe applied to different domains

Several pairs of sources apply what amounts to the same reframe to different specific domains
rather than genuinely disagreeing: a plateau in physical training and a plateau in personal-pattern
change are both reframed as a necessary, invisible-tension-building phase rather than a stalled
process; the "arrival fallacy" (achievement not producing expected fulfillment) is illustrated with
both a championship win and, in a different source, a thought-experiment about permanent
guaranteed pleasure (the "experience machine") — both concluding that the sought-after end state
doesn't deliver what was expected of it, from a sports-psychology angle in one case and a
philosophical angle in the other.

## Explicit addiction/substance comparisons as a rhetorical device

Two sources reach for direct addiction or substance-dependence comparisons to make a point about a
non-substance behavior: one explicitly states that phone use is "the same neurochemistry" as
substance addiction; another compares a philosophical thought experiment about guaranteed pleasure
directly to "a heroin addiction" narrowing a person's life. Neither source is presenting a clinical
diagnosis or citing addiction-medicine research — both use the comparison rhetorically, to make an
abstract mechanism (dopamine anticipation, the pull of guaranteed pleasure) feel concrete via a
widely-understood reference point. Worth keeping the distinction visible: this collection's sources
are describing behavioral patterns and drawing an analogy to addiction, not making claims about
diagnosable substance-use disorder.
