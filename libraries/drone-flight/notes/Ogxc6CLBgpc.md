# DJI Air 3S: Beginner's Guide (Start Here!)

## Central claim

**This is a first-flight walkthrough for the Air 3S specifically, framed around what changed
from the older Air 3 (sensor, obstacle-avoidance hardware, internal storage) before any flying
starts, then a full pre-flight checklist before takeoff.** `[00:00]` "In today's video we're
going to be doing the beginner guide to the [Air 3S], all the new features, all the upgrades,
and how to get started with your first flight." The hardware framing is explicit about what
carries over versus what's new: `[01:00]` "the battery in itself is exactly the same as the Air
3... that's not very common for them to actually keep the same battery from model to model.
Same for the propellers."

## What changed from the Air 3 (00:00–02:02)

- **Sensor and obstacle avoidance**: `[00:00]` "This is a 50 megapixel [sensor] instead of 48
  megapixel, f1.8 although the [Air 3] was f1.7... the filters, if you're wondering, do not fit
  if you have Air 3 filters, these are brand new filters." The front obstacle-avoidance bar "now
  uses [LiDAR]... the functionality is exactly the same except the technology is a little bit
  different, so this is supposed to be getting better obstacle information compared to what we
  had before, which was using just cameras."
- **Storage**: `[01:00]` "42 gigs of internal storage compared to — I actually don't remember
  what it was in the Air 3, but I think it was a lot less."
- **Low light and return to home**: `[01:00]` "one of the big advantages of the [LiDAR] is that
  as far as low light conditions, this will be a lot better... also as far as return to home, we
  have the advanced return to home, which is a bit smarter than it was before, where it's going
  to be able to find the most optimal way of getting back to the user."
- **Flight time trade-off, stated as a measured comparison rather than a spec-sheet number**:
  `[01:00]`–`[02:02]` "from our testing we had a minute and 40 seconds less than the Air 3 in the
  same exact environment. Now, is that noticeable? I don't know."

## Pre-flight checklist (02:02–06:09)

| Check | What to look for | Source guidance |
|---|---|---|
| Flight mode switch | N / S / C on the controller | `[02:02]` "N for normal, S would be for sport mode, and then C would be for cinematic" |
| RTH altitude | Set above the tallest obstacle nearby | `[03:03]` set to clear "the tallest tree or the tallest building that you have around"; presenter uses 180 ft |
| Max altitude | 400 ft default legal ceiling, raise only if terrain requires it | `[03:03]` "if you live in a flat area and you don't want to exceed 400 ft you probably want to sit that at 400, 450 ft just to stay within limits" |
| Obstacle avoidance mode | Bypass recommended | `[04:06]` "right now we have it on bypass, which is great, I'm going to keep it as it is" |
| RTH routing | Optimal | `[04:06]` "as far as the RTH we have it set to optimal... it's a good way for the drone to come back and use the most optimal route" |
| Camera profile | Normal vs. D-Log M, manual white balance | `[04:06]`–`[05:08]` "I recommend getting off of the automatic white balance, we set ours to 5600 so all of our cameras match" |
| Weather | Visual wind check (or an app) | `[05:08]` "just look outside, see if the wind feels like it's really moving you around, in which case you don't want to fly" |
| Airspace | Airspace-authorization app | `[05:08]` "you can download an app called [B4UFLY/AirControl]... to see if you need approval" |
| Satellites | Wait for a strong lock before takeoff | `[06:09]` presenter notes "28 satellites" before takeoff, described as "enough satellites to take off" |

## Manual vs. automated point-of-interest orbit (09:14–12:16)

The manual technique is given as a specific dual-stick input, not just "circle the subject":
`[10:14]` "we're going to be using the yaw on the left side here... using the right stick going
to the right and the left stick going to the left at the same time... you will need to use the
right stick to go forward a little bit as well at the same time in order to not get too far away
from your subject." The automated equivalent is presented as easier but less reliable at
recognizing the subject: `[11:16]` "you would have to go on the screen, highlight your subject,
hope that it picks it up... now go in the direction where we want to go to record." Both produce
comparable results in the presenter's own assessment: `[12:16]` "we'll see which one looks best,
my shot or the automated shot."

## Active track and return to home (13:17–17:22)

Active track is demonstrated on a car and then a person, with a caution about staying within
sight and airspace awareness: `[13:17]` "we're still within visual line of sight... [there's]
another airplane nearby, I am nowhere near where they would be, but you would want to be looking
around to see if anybody is coming in your airspace." Return to home is shown triggered manually
near critical battery: `[16:21]` "our battery is actually getting pretty low, we have 4 minutes
left, we just got a warning... I'm going to push the home button here and hold it... it's going
to return to home... it's telling us exactly where it's going to go in 3D." The video ends with
an explicit caution against repeating its own margin: `[17:22]` "we are at critical battery
voltage... we pushed it a little too long, I don't recommend going to that level if you can
avoid it."

## Warnings and pilot signals addressed

- **Low battery return-to-home trigger**: `[16:21]` a 4-minutes-remaining warning preceded the
  manual RTH trigger in this flight.
- **Critical battery voltage as a hard stop**: `[17:22]` explicitly flagged as pushed too far —
  "I don't recommend going to that level if you can avoid it."
- **Nearby manned aircraft as an active watch item, not just a one-time check**: `[13:17]` "man,
  aircraft nearby... you would want to be looking around to see if anybody is coming in your
  airspace."
- **Flying over water calls for closer visual monitoring during RTH/landing**: `[16:21]` "you
  want to make sure that you keep an eye on the drone... especially when you're over [half]
  water like we are right here."
- **Satellite count as a pre-takeoff gate**: `[06:09]` presenter waits for a high satellite count
  before takeoff, "we have enough satellites to take off."

## Glossary terms introduced

- **Bypass (obstacle avoidance mode)** — the drone routes around a detected obstacle and
  continues on its path, as opposed to stopping; the presenter's preferred setting `[04:06]`.
- **Optimal (RTH routing)** — an advanced return-to-home mode that calculates "the most optimal
  route" back to the pilot rather than a fixed path `[04:06]`.
- **D-Log M** — a flat, low-contrast color profile intended for color grading in post-production,
  contrasted here with the default "normal" profile `[04:06]`.
